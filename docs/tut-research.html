Web research

Ask for current information and get an answer with sources. The assistant selects when to use the web. It runs a search, reads the best pages, and returns an answer with links. You do not call a tool yourself.

The knowledge of a model stops at its training cutoff. For recent information, for example a launch, a price, a score, or a policy change, the assistant uses the web. It can call two tools. web_search finds current results. web_fetch reads the text of specified pages. This tutorial shows how to start a web search, what you see during the search, and how to examine the sources.

web_search uses a Tavily API key. Without a key, web_search does not search. If an Amazon Bedrock AgentCore MCP server with browser tools is enabled, the tool tells the assistant to use that browser. If not, the tool returns a message that web search is not configured. All the other functions of the app operate without a key. See Configuration.

Before you start

Web search uses Tavily, a search API. The free tier of Tavily is sufficient for personal use. The tavily_api_key setting is empty in a new install. Add the key in one of two ways:

  • Settings (recommended). Open Settings > General. Paste the key into the Tavily API Key (for web search) field.
  • Environment variable. Start the backend from a shell that exports TAVILY_API_KEY. The environment variable has priority over the stored value. This method applies only to a source install that you start from that shell. The Mac app does not read this variable from your shell profile. After you change the variable, start the backend again. 
    export TAVILY_API_KEY=tvly-...

web_fetch reads one URL and does not use Tavily. Thus you can paste a link and ask about it without a key.

Ask a question that needs the web

You do not enable a function in the chat. Ask your question. Make it clear that you want current facts. If you want sources, ask for them.

  1. Type your question

    Use a question about recent events. Example:

    What did Anthropic announce at their last developer
conference? Cite sources.

  2. The assistant selects the tool

    If the model has the answer in its training data, the assistant answers directly. If it needs current facts, it calls web_search. You do not select the tool.

  3. Look at the activity row

    Each tool call shows in the activity row of the turn. The row is one line that shows the searches and the fetched pages. Web search and web fetch are read-only, so no approval card shows.

  4. Read the answer and its links

    The answer contains links to the pages that the assistant used. Open a link to examine the source. If you ask for sources in the question, the answer contains the links more reliably.

To make the assistant use the web, write phrases such as "as of today", "the latest", or "cite sources". To read one page, paste the URL and write "summarize this".

The two web tools

Research uses two tools with different functions. The two tools are read-only.

ToolWhat it doesNeeds Tavily?
web_searchSends the query to Tavily and returns a maximum of 5 results. Each result has a title, a URL, and a short snippet.Yes
web_fetchGets one public page over HTTP or HTTPS and returns its text. The output starts with the URL, the HTTP status, and the page title. Then it gives the HTML as plain text with heading and list markers. The tool cuts long pages at 30,000 characters. The request stops after 15 s.No

web_fetch connects only to public addresses. It refuses private, loopback, and link-local addresses, and the cloud metadata address. Thus a page cannot make the app read data from your local network.

A usual research turn uses the two tools in sequence. web_search finds possible pages. Then the assistant calls web_fetch to read the best pages before it answers. When you paste a URL, the assistant usually calls only web_fetch. For the full list of tools, see Agent tools.

Read a page that you paste

You can paste a link and ask about it. The assistant reads that page with web_fetch:

Summarize https://example.com/some-long-article and pull
out the three main claims.

web_fetch does not use Tavily, so this procedure operates without a Tavily key. The app sanitizes the fetched pages before it shows them. Thus a page with a prompt injection cannot run scripts in the app. The security model shows how the app handles web_fetch output as untrusted data.

The network of commands

The network of a shell command is separate from the two web tools. A command in the sandbox can connect to all hosts. The app does not limit the network of commands. See Sandbox & security for the limits of the sandbox.

Examine the searches

You can examine the source of each statement. The app puts the tool calls of a turn into one activity row. When you expand the row, it shows one line for each call. Each line opens to show the raw output of the call. This is your audit trail.

  • Expand the activity row to see the web_search query and its results.
  • Open the output of a web_fetch call to see the page and the returned text.
  • Open the links in the answer to read each source.

If a step has an error, the row opens automatically. Thus you can see a failed search immediately.

These tool calls are usual tool calls in the chat loop. The chat pipeline sends a tool event when each search or fetch starts. The activity row shows these events.

Why research does not ask for approval

Web search, web fetch, and document extraction are read-only. They cannot change your files, run commands, or change git. Thus no approval card shows in any permission mode. The worst result of a research turn is an incorrect answer, not a harmful action. Approvals apply when the assistant can write, run, or commit, as in the workspace.

Troubleshooting

SymptomCause and correction
The assistant answers from its training data, but you want current factsAsk more clearly ("as of today", "cite sources"). Or paste a URL so that the assistant uses web_fetch.
No search occursThe Tavily key is missing. Add the key in Settings. See Configuration.
Search operated before, but now failsThe key is expired or rotated. Put the new key in Settings. If you use TAVILY_API_KEY, it has priority over the stored value. Set the new value and start the backend again.
A pasted URL does not loadThe page blocks automated requests, or it needs a login. Use a public copy of the page, or paste the text.

To examine the dependencies and the AWS access, run /doctor in the chat input.
