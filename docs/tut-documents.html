Working with documents

Drop a PDF, a Word document, a deck, a spreadsheet, or an image into the chat. Then ask questions about it in plain English. The app extracts the text on your Mac. The document stays in the conversation for all the follow-up questions.

Example: you have a vendor contract of 40 pages, and a call in 3 minutes. You must find the payment terms. This tutorial shows the procedure: attach the file, ask, and ask again. You do not upload the file again.

The goal

Analyze a document quickly. Give the file to the assistant and ask specific questions. The procedure is: attach, ask, read, and ask again. You do not need a conversion step, a separate viewer, or copy and paste.

Attach the file

You can attach a file to the composer in two ways. The result is the same:

  1. Drag the file into the chat

    Drop a PDF, a Word document, a deck, a spreadsheet, or an image on the chat composer. This is the fastest method for a file on your desktop.

  2. Or click the paperclip

    Click the paperclip (Attach) button in the composer and select a file. For a file in a connected workspace, you can also use the /file: menu.

  3. Look at the chip

    A chip with the file name shows in the composer. During the upload, the chip shows "(uploading…)". When /api/upload completes, the label goes away and you can send. To remove a file, click the x on its chip. This also stops an upload that is in progress.

The upload starts when you attach the file, not when you send the message. Usually the app completes the extraction before you complete your question. Thus Enter sends without a delay.

Ask, then ask again

When the chip is ready, type your question and press Enter. Example:

What are the payment terms, in plain English?

The assistant reads the document text and returns an answer, for example "Net 30 from the invoice date, with a 1.5% monthly late fee." Then ask a follow-up question. You do not attach the file again:

And the termination clause?

The document is already in the conversation. Thus the assistant answers from the same source. Ask as many questions as necessary, one question in each turn.

This also operates after a restart. The first turn that uses an upload connects it to the session, and the session stores the extracted content. Thus the conversation answers from the same document when you open it again.

The app keeps a connected attachment for 30 days after the last turn that used it. Each use starts the 30 days again. When you delete the session, the app deletes its attachments. The app deletes an upload that you did not send after 3 hours.

What occurs on your Mac

The app extracts the file text locally. When you attach a document, the app converts it to Markdown text on your Mac. The app does not send the file when you attach it. The app sends the extracted text only when you send the chat message. The model gets the document text, not the original file.

server/extract/__init__.py selects the converter from the file type. A general converter (MarkItDown) converts most formats. Special converters are for PDFs, spreadsheets, and images. The text stays in the conversation history. Thus each follow-up question in the session uses the same document.

The extraction is local, so a document that you do not send stays on your Mac. The extraction operates without a network connection. The app uses the network only for the chat call to a cloud model. In Local mode, the default of a new install, the chat model is on-device. Then the document text does not go off your Mac.

Supported file types

Whisper Studio accepts the usual office formats, images, audio, and video:

TypeResult
PDF (.pdf)Text extraction. For a scanned PDF or a PDF with only images, the app uses OCR to get the text.
Word (.docx)The document body as Markdown, with the headings.
PowerPoint (.pptx)The text of all the slides.
Excel and CSV (.xlsx, .xls, .csv)Small sheets in full. The app takes a sample of large sheets (see below).
Images (PNG, JPEG, GIF, WebP)The app sends the image as a vision block. The app also uses OCR to get the text, so text-only models can read it.
Audio (.mp3, .wav, .m4a, .flac, and more)The app transcribes the audio on your Mac into a transcript with timestamps and speaker labels. The app keeps only the transcript.
Video (.mp4, .mov, .webm, .mkv, and more)The same transcript, and a maximum of 20 sample frames. The app reads the text on each frame and adds it as notes with timestamps. A vision model also gets the frames.
Text, Markdown, HTML, EPUB, JSON, XML, ZIP, and frequent code filesThe app converts the content to Markdown text.

The app does not accept the old binary Office formats .doc and .ppt. The app shows a clear message. Save these files as .docx or .pptx first.

Large spreadsheets get a sample

A spreadsheet with thousands of rows does not fit in the context window. The app keeps a small sheet in full. If the converted text is more than approximately 60,000 characters, the app makes a schema plus sample. The sample has the dimensions of each sheet, the header row, and the first 20 rows. The assistant can then ask for specified rows or columns. The same rule applies to a large CSV file.

Size limits

The maximum size for documents and images is 50 MB. The maximum for audio and video is 200 MB, because the app keeps only the transcript. If a file is too large, the app shows the reason from the backend. Then you can make the file smaller or divide it. The app adds a maximum of approximately 150,000 characters of text for each attachment. Thus one large file does not fill the conversation.

If an upload fails, read the notice. It gives the real reason, for example a file type that the app does not accept, or a file that is larger than 50 MB. If the notice says that the server is not available, the backend of the app does not run.

Tips

Attach many files

Drop or select many files at the same time. Each file gets its own chip. The assistant can compare the files in one question.

Ask specific questions

"Summarize the payment and termination sections" is better than "summarize this". A specific question gives a specific answer from a long document.

Use files from your workspace

For a file in a connected repository, the /file: menu attaches it from the chat. See The workspace IDE.

One document, many turns

You upload the file one time. Ask more questions in the same session, and the document stays in the context.

Make documents

The app can also make documents. Ask for "a Word doc of this summary" or "a deck from these notes". Whisper Studio makes the finished file in a standard layout: A4 Word documents, 16:9 decks, formatted spreadsheets, and A4 PDFs. The app saves the file after one approval card, and it does not ask where.

The standard layouts are fast but fixed. For a special format, ask for it. Examples are cell shading, merged columns, a logo, or a number format.

Also ask when you want to change a document that exists. Then the assistant writes python-docx, python-pptx, or openpyxl code for your file. The approval card shows the code before it runs. The code changes a copy, not your original file. For the full procedure, see Saving files and creating documents.
